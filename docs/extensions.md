# Extensions

Extensions add focused features to Million Dollar Script without making the core plugin harder to configure. Open **Million Dollar Script > Extensions** in WordPress to browse compatible releases, connect tester or customer access, install packages, and manage updates.

Availability, pricing, and compatibility can change between releases. Review the extension catalog and the details shown in WordPress before installing an extension.

## Free Extensions

### ImageGrid Rendering

Connect Million Dollar Script to ImageGrid for hosted rendering of large grids, account status, quota visibility, and delivery controls. The WordPress connector is free; hosted ImageGrid plans are purchased separately.

### WooCommerce Checkout

Use WooCommerce for payments, taxes, currencies, order management, and compatible checkout extensions while keeping commerce logic outside the core plugin.

### Contact Form

Create contact forms with configurable fields, email delivery, stored submissions, and basic spam protection. Fields integration is available when the Fields extension is active.

### Analytics

Add Google Analytics 4 or approved custom tracking snippets, record useful placement events, and review a concise analytics dashboard in WordPress.

### SEO Basic

Add search metadata, social previews, structured data, and scalable XML sitemaps for Million Dollar Script grids and placements while remaining compatible with broader SEO tools.

### Launch Wall

Create scheduled launch slots, featured placements, buyer submissions, and moderation workflows for products, apps, books, events, campaigns, and other launches.

### Attention Cooperative

Manage sponsor-inventory partnerships with explicit approvals, capacity limits, scoped exposure, audit history, and revocation. Each partner controls what they share and when.

### Bounty Engine

Publish bounty and request listings with optional posting fees, submissions, moderation, and status tracking without holding project funds in escrow.

### Local Money Map

Create moderated local sponsorship maps with locations, trails, offers, QR target links, reporting, and printable QR materials for sponsors and community promotions.

### Revenue Reports

Review revenue trends, order status, and grid performance across useful date ranges, then filter and export reports for bookkeeping and planning.

### Sponsorable AI Tools

Create sponsor-supported calculators, planners, quizzes, generators, and guides with lead capture controls, moderation, and clear ownership of published tools.

### SponsorBoard

Build sponsor boards with sellable slots, booking windows, creative uploads, moderation, and placement management through compatible Million Dollar Script payment providers.

### Proof of Support Passport

Create site-local supporter grants, customizable badges, and proof pages without exposing personal information by default. Supporters can opt into directory visibility when enabled.

## Premium Extensions

Premium extensions require an active license or approved tester access for installation, updates, and private documentation.

### Fields

Build reusable placement field groups with drag-and-drop ordering, validation, live previews, and integrations for contact forms, popup templates, and compatible extensions.

### Translation

Review and manage translatable strings from Million Dollar Script core and active extensions in one workspace with status, scheduling, and translation tools.

### Missions

Publish goal-driven missions with paid support, progress milestones, sponsor recognition, and moderated supporter listings while protecting private supporter details.

### Revenue Agent

Use supported AI providers to draft sponsor packages, proposal pages, opportunity audits, and outreach copy from administrator-approved context. Suggestions remain reviewable and are never published or sent automatically.

### Search Visibility

Find search issues across public grids, add valid Product and Offer inventory schema, control sitemap inclusion, and monitor Million Dollar Script search appearance.

### Advertiser Workspace

Give verified customers and guest purchasers a private workspace for active, pending, expiring, action-required, and historical placements, including supported creative updates, payments, and renewals.

### Campaign Scheduler

Schedule when approved grid placements and compatible SponsorBoard bookings are visible with timezone-safe windows, conflict checks, previews, retry recovery, and transition history.

### Time Capsule

Create future-reveal campaigns for launches, offers, memories, predictions, and sponsor moments with controlled submission, moderation, scheduling, and reveal behavior.

## Finding and Installing Extensions

Use the [Million Dollar Script extension catalog](https://milliondollarscript.com/catalog) to compare available packages. In WordPress, the **Extensions** page shows only packages compatible with the installed Million Dollar Script generation and provides the relevant install, license, update, and documentation actions.

Before enabling an extension on a production site, test it on staging, review its setup page and permissions, and confirm that any payment, email, scheduled-task, or external-service settings match the site's requirements.
