# Security Policy

## Supported versions

Security fixes are provided for the latest maintained Million Dollar Script 3.x release. Test builds may receive fixes before the next stable package is published.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through [milliondollarscript.com/contact](https://milliondollarscript.com/contact/). Do not open a public issue containing exploit details, credentials, customer information, order data, or private site URLs.

Include the Million Dollar Script version, WordPress and PHP versions, affected feature, reproduction steps, and the minimum sanitized evidence needed to investigate. Do not test destructive techniques against sites you do not own or administer.
